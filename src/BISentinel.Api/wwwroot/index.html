    Naming rules

    Regular expressions are applied to table, column, measure, and placeholder names.

    Regex help and examples

    Rules use .NET regular expressions and ignore letter case. Use ^ and $ to require the whole name to match; without them, a matching substring can be enough.

    ^[A-Z][A-Za-z0-9]*$ — begins with a letter, followed by letters or digits (for example DimCustomer).

    ^[A-Z][A-Za-z0-9]*( [A-Z][A-Za-z0-9]*)*$ — title-cased words separated by single spaces (for example Total Sales).

    ^Column\d*$ — the word Column followed by zero or more digits (for example Column or Column12).

    Common tokens: [A-Z] one uppercase-range letter · [A-Za-z0-9] a letter or digit · \d a digit · * zero or more · + one or more · (...) group · | alternative.
